## 🧠 About Me

> 🔐 **DevSecOps** · 🛠️ **Full-Stack** · 🤖 **AI Automation** · ☁️ **Cloud-Native**

I design and ship **production-grade SaaS platforms** where **security isn't an afterthought** — it's wired into every layer from infrastructure to API to frontend.

- 🚀 Building **multi-tenant ERP/EMS systems** with role-based access control
- 🔐 Applying **DevSecOps principles** — OWASP, JWT hardening, zero-trust API design, secrets management
- 🤖 Automating everything with **n8n**, **Ollama LLMs**, **MCP (Model Context Protocol)**, and **agentic AI workflows**

## 🔐 DevSecOps Practices

<div align="center">

| Layer | What I apply |
|---|---|
| **API Security** | JWT hardening · OAuth2 · role-based access control · rate limiting |
| **Secrets Management** | Env-based secrets · no credentials in code · `.env` guards in CI |
| **Container Security** | Non-root Docker images · health checks · minimal base images |
| **CI/CD Security** | GitHub Actions with secret scanning · automated TS type checks · lint gates |
| **OWASP Top 10** | Input validation · SQL injection prevention · XSS guards · secure headers |
| **Auth Architecture** | Zero-trust · refresh token rotation · SSR-safe auth · session invalidation |
